# Módulo 3: Chat (20 min)

**Material:** [`docs/modulos/03-chat.md`](../../docs/modulos/03-chat.md)

| Min | Qué hacer |
|---|---|
| 0–5 | Panel vs inline chat. Muestra `Ctrl+I` sobre una función de `src/app.py` |
| 5–10 | Los tres modos. Usa la regla: Ask entiende, Plan decide, Agent ejecuta |
| 10–14 | Slash commands: demuestra `/explain` y `/doc` en vivo |
| 14–20 | Selección de modelo: la **misma pregunta con dos modelos**, compara velocidad y profundidad |

## Demo sugerida

1. `Ctrl+I` sobre `crear_producto`: "agrega validación de precio negativo".
2. Modo Ask: "¿qué endpoints expone esta app?".
3. Cambia de modelo y repite.

## Errores frecuentes

- Usar Agent para preguntas simples (gasta cuota y arriesga cambios).
- Los nombres de modos/botones pueden diferir en la versión instalada: avísalo al grupo.

## Transición

Pregunta: "¿Qué pasa si Copilot no conoce nuestras reglas?" → Módulo 4.
