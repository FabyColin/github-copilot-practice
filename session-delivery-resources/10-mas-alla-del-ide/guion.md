# Módulo 10: Más allá del IDE (25 min, demo del instructor)

**Material:** [`docs/modulos/10-mas-alla-del-ide.md`](../../docs/modulos/10-mas-alla-del-ide.md)

Los alumnos **observan**: no hay ejercicio. Prepara todo con anticipación (ver [`00-setup`](../00-setup/demo-setup.md)).

| Min | Qué hacer |
|---|---|
| 0–10 | **Cloud agent**: muestra el issue, cómo se asigna a Copilot y el PR **ya generado**. Revisa los commits y el log de la sesión |
| 10–17 | **Code review**: agrega a Copilot como revisor en un PR preparado y comenta lo que encontró |
| 17–23 | **MCP**: muestra `mcp.json`, las herramientas que expone el servidor y una consulta que use la documentación de Microsoft Learn |
| 23–25 | Preguntas |

## Plan B

Si el servicio no responde o la tarea tarda: muestra el PR previamente generado y capturas. **No esperes en vivo** a que el agente termine.

## Mensajes clave

- "Un issue vago produce un PR vago."
- "El code review automatizado es la primera capa, no la última."
- "Instala solo servidores MCP en los que confíes."

## Archivos de apoyo

- [`issue-demo.md`](issue-demo.md): ejemplo de issue bien escrito.
- [`mcp.json.ejemplo`](mcp.json.ejemplo): configuración del servidor de Microsoft Learn.

## Después de la demo

Desasigna el issue, cierra los PR de demo y elimina `.vscode/mcp.json` si lo creaste.
