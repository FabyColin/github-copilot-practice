## Referencia rápida de atajos (VS Code, Windows/Linux)

| Acción | Atajo |
|---|---|
| Aceptar sugerencia | `Tab` |
| Descartar sugerencia | `Esc` |
| Siguiente / anterior sugerencia | `Alt+]` / `Alt+[` |
| Aceptar una palabra | `Ctrl+→` |
| Panel de sugerencias | `Ctrl+Enter` |
| Chat inline | `Ctrl+I` |
| Abrir el chat | `Ctrl+Alt+I` |

En macOS cambia `Ctrl` por `Cmd` y `Alt` por `Option`. Los atajos pueden variar entre versiones: verifica en *Keyboard Shortcuts*.

## Referencia rápida del chat

| Elemento | Uso |
|---|---|
| `/explain` | Explica el código seleccionado |
| `/fix` | Propone una corrección |
| `/tests` | Genera pruebas |
| `/doc` | Documenta el código |
| `#file` `#selection` `#codebase` | Variables de contexto |
| `.github/copilot-instructions.md` | Reglas que aplican a todo el proyecto |
| `.github/prompts/*.prompt.md` | Prompts reutilizables |
